# MindBody Health Risk AI

## Overview
MindBody Health Risk AI is an AI-powered healthcare application developed for SDG 3: Good Health and Well-Being.

The application predicts:
- Physical Health Risk (Diabetes)
- Mental Wellness Risk

It also provides:
- Health Dashboard
- AI Chat Assistant
- Personalized Action Plans

## Technologies Used
- Python
- Streamlit
- Scikit-Learn
- Pandas
- Plotly

## Datasets
- Pima Indians Diabetes Dataset
- Mental Health Dataset

## Model Performance
- Physical Health Model: 73% Accuracy
- Mental Health Model: 71% Accuracy
